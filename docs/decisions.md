- 2026-11-06 — **Next.js, not Vite** (user request). Must be static export (`output: 'export'`) to stay server-less; Firebase Hosting serves `out/`. `next build` verified. Engine is framework-independent, unaffected. Next auto-edited `tsconfig.json` (jsx → react-jsx, extra include) on first build.
- Engine implemented (pure TS, ports-only): state machine, orchestrator `InterviewEngine`, evaluator (prompt, zod validation, 1 retry, graceful degrade), feedback builder, selector + adaptive difficulty, local router, safety guard, VADER wrapper. Firebase adapters written (`src/adapters/firebase/`) — type-checked only, never executed.
- **Start difficulty = 1** (gentle, psychologically safe). Adjust ±1 after relevance ≥0.75 / <0.50.
- **Injection defence = relevance cap 0.4** when a local pattern matches OR the model flags it. Deterministic; not "obeying" the answer. Risk: false positives on legitimate answers that quote such phrases; revisit after the live run.
- **Confidence = 0.7·model + 0.3·VADER(normalised)**. The 0.3 is an unvalidated heuristic (not from the thesis); tunable in `config.ts`. VADER measures sentiment, not confidence — state this honestly in the thesis.
- **Clarification/off-topic/greeting** are never scored; the question is re-shown. Clarification does NOT reveal key points.
- Summary is template-based (no 2nd Gemini call) to keep "one call per answer".
- Persistence is gated twice: `StorePort` no-op unless opted in + Firestore rules require `saveProgress==true`.
- Firestore rules written but UNTESTED (no emulator tests) — do not deploy.
